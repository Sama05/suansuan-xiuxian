# 兵解 · 转生系统 —— 设计草案（待确认）

> 状态：**草案，未实现。** 本文只给方案，等确认后再动代码。
> 背景：主线在元婴处断了（`realms` 只到 id 4，元婴的 `need = 5e10` 是「从元婴突破所需」，
> 但没有 id 5）；`sim.js` 实测 11.9 小时到元婴，之后进度条恒为 100%。
> 公司 / 市场 / 股市这些设计量最大的系统，实际全落在「通关之后的沙盒」里，缺一个终局目标去驱动它们。

---

## 一、这个系统要解决什么

| 问题 | 兵解怎么解 |
|---|---|
| 主线 12 小时通关后没有目标 | 转生把「终点」变成「一轮的终点」，每一世都是一次完整的爬升 |
| 设计支柱「重启有得」没有落地 | 每一世都积累永久加成，失败（将来渡劫失败）也保留收益 |
| 公司 / 市场 / 股市缺驱动 | 转生后算力被压低 → 必须靠产业线与资本线补产能，这三条线从「沙盒」变成「刚需」 |
| 4.7 里「离线收益可升级」是死内容 | 道行加成里正好有一档「离线上限 / 离线系数」，把它接通 |

## 三、保留 / 清空清单（核心，需要逐项拍板）

这张表是整个系统的骨架。我的建议列在「建议」列，**请逐项确认或改**。

### 3.1 修仙线

| 项 | 建议 | 理由 |
|---|---|---|
| 境界 realm | **归 0**（凡人） | 兵解的本义 |
| 灵气 qi | **清零** | 它是境界货币，留着等于没归零 |
| 功法（已习得清单） | **保留** | 手册已定规则 |
| 功法等级 | **清空**（由算力重新换算） | 手册已定规则 |
| 熟练度进度 mastery | **清空** | 手册已定规则（下一世重新攒） |
| 熟练度段位 tier | **保留** | 手册已定规则 |
| 被动常驻 passive | **保留** | 段位保留了，常驻跟着保留，否则规则自相矛盾 |
| 道行 / 转生加成 | **保留**（全新字段） | 转生的意义所在 |

### 3.2 科技线（**这里有个关键取舍，需要你定**）

| 项 | 方案 A：设备全清空 | 方案 B：设备保留（推荐） |
|---|---|---|
| 设备数量 | 全部归 0 | 全部保留 |
| 算力 / AI 加成 | 归 0 | 保留，但吃一个「转生折扣」 |
| 神识 | 只剩境界基础值 | 境界基础值归 1，设备倍率保留 |
| 手感 | 彻底重来，第二世前 1 小时会很空 | 起手就有产能，能直接推产业线 |
| 风险 | 太慢，玩家会烦 | **可能秒回元婴**（算力在 → 功法等级立刻拉满 → 灵气飞涨） |

**我推荐方案 B + 折扣**，具体是：

```
转生折扣 = 0.35 + 0.05 × min(已完成兵解次数, 9)      // 0.35 → 0.80 封顶
设备实际算力 = 原算力 × 转生折扣
神识设备倍率 = 原倍率 × 转生折扣
```

这样第一世转生后算力只剩 35%，第二世 40%……最多回到 80%。折扣是可调旋钮，`game-config.js` 里一个字段。

> 如果你觉得「清空更爽、更有仪式感」，选方案 A 也成立，只是必须同时把「道行加成」的起步补偿给足（例如道行可直接兑换起手设备），否则第二世的开局会非常难受。

### 3.3 产业线与资本线（**第二条关键取舍**）

| 项 | 建议 | 理由 |
|---|---|---|
| 公司 founded | **保留** | 它是「资本型资产」，不靠境界驱动 |
| 生产线 lines（含每台的产物 / 产能配置） | **保留** | 上面那条的自然延伸 |
| 仓库等级 / 库存 | **保留** | 同上 |
| 公司累计统计（cycles / totalRevenue / totalUpkeep） | **保留** | 只是统计 |
| 股市持仓 shares / 成本 cost | **保留** | 强制平仓对玩家是纯伤害，且没有叙事理由 |
| 股市统计（realized / totalFee / totalTrades） | **保留** | 同上 |

**为什么建议全保留**：兵解后的处境会变成「厂房还在，但没电了」——
工业算力来自**设备算力**，而设备算力被转生折扣压到 35%，
于是产业线从「躺赚」变成「要重新配算力才能开满」。
这是**耦合**，不是矛盾：**公司是资产，算力是动力**。
玩家必须重新决定这 35% 的算力怎么分：给工业产能保住产业现金流，还是给修仙方向抢速度。
—— 这个取舍本身就很有玩法价值，比「资产清零」好得多。

### 3.4 硬通货

| 项 | 建议 |
|---|---|
| 金钱 money | **清零**（回到起手 20） |
| 灵石 spiritStone | **清零** |
| 精力 | **重置到新境界的上限**（凡人 100） |
| 投向分配 alloc | **重置为 100% 修仙**，锁定项自动归零 |
| 时间档位 | **回落到档 1**，`autoTier` 保持开启，突破后自动跟 |
| 当前工作 / 工作进度 | **重置**（回到「街头发传单」） |
| 工作完成次数 jobDone | **保留** | 否则升职链要重跑一遍，纯折腾 |
| playTime（行情时钟） | **保留，绝不允许倒退** | 它驱动市场与股市的「期」，倒退会让抛压 / 冲击结算错乱 |
| gameSeconds（游戏内时间） | **保留** | 日期不该倒流 |

## 四、道行（转生专属资源）与永久加成

### 4.1 单次收益

```
道行 = 100 ×(1 + 0.6 × 已完成兵解次数) × 境界系数
```

- 境界系数：元婴 = 1.0（当前唯一可兵解的境界）。
- 第 1 次兵解 → 100 道行；第 2 次 → 160；第 3 次 → 220……
- （将来若加更高境界，境界系数按 `1 + 0.3 × (境界 − 4)` 递增。）

**刻意不对「资产总量」敏感**：不然玩家会先囤到天量资产再兵解，
把转生变成一次性的暴富操作，而不是一轮轮的节奏循环。

### 4.2 加成清单（建议值，成本按 ×1.8 递增）

| 加成 | 每级效果 | 上限 | 首级成本 | 设计意图 |
|---|---|---|---|---|
| 神识根基 | 境界基础神识 +5 | 8 级 | 40 道行 | 直接抬高每一世的起跑线 |
| 灵气亲和 | 灵气吸收速度 +8% | 10 级 | 60 道行 | 加速主循环 |
| 精力淬炼 | 精力上限 +10% | 5 级 | 50 道行 | 放开工作产能 |
| 离线延展 | 离线系数 +0.05（0.3 → 0.5） | 4 级 | 30 道行 | **接通 4.7 的死内容** |
| 离线恒长 | 离线上限 +6 小时（48 → 72） | 4 级 | 30 道行 | 同上 |
| 市场人脉 | 股市手续费 −0.05%（0.5% → 0.25%） | 5 级 | 45 道行 | 让资本线后期更可行 |

**全部加成必须设硬上限**（上表已给），否则长线会失控。这是 6.4 里「数值上限」那条约束的落实。

### 4.3 防正反馈（必须先做的前置改动）

原设计的风险链路是：
`境界 ↑ → 神识 ↑ → 算力 ↑ → 功法修炼 ↑ → 灵气 ↑ → 境界 ↑`

而现在「神识根基」这条加成会**直接加在回路的第一环上**，
所以**在实现兵解之前，必须先给神识回路加阻尼**，否则转生会把这条回路直接推到失控。

建议做法（三选一，需要你定）：
- **A. 次线性化**：神识对实际算力的加成从 `(1 + 神识 × 0.02)` 改成 `(1 + 神识 × 0.02)^0.5`
- **B. 改加法**：改成 `1 + min(神识 × 0.02, 一个大常数上限)`
- **C. 分层**：境界基础神识线性、设备神识次线性

我倾向 **C**：境界那一份（转生加成走这里）保持线性、手感清晰；
设备那一份（玩家可以无限堆）次线性、防止后期爆掉。

## 五、存档结构

```js
s.rebirth = {
  count: 0,                    // 已完成兵解次数
  dao: 0,                      // 未分配道行
  daoTotal: 0,                 // 历史累计（只增不减，防作弊）
  perks: {                     // 各项加成的等级
    shenshi: 0, qiSpeed: 0, energyMax: 0,
    offlineRatio: 0, offlineHours: 0, marketFee: 0,
  },
  best: { realm: 0, money: '0', playTime: 0 },   // 历史最佳，用于展示
  history: [],                 // 每世摘要（便于「传记」类展示）
};
```

- `hydrate` 逐项夹范围；`count / daoTotal / perks.*` 走 `/api/save` 的**只增不减**保护。
- `count` 只由服务端 `/api/action` 的 `rebirth` 动作推进（与 `founded` 同一套单向门逻辑）。
